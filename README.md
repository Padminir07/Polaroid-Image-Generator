# Polaroid Image Generator using OpenCV

## Overview
This project generates a Polaroid-style image effect using OpenCV. 
It adds borders and styling to input images to simulate a classic Polaroid photograph look.

## Technologies Used
- Python
- OpenCV
- NumPy
- Google Colab

## Methodology
1. Load input image using OpenCV.
2. Add white border frames.
3. Adjust bottom padding to mimic Polaroid layout.
4. Save and display the final styled image.

## Applications
- Image styling
- Photo frame generation
- Computer vision practice
